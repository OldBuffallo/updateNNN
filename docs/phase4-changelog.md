## Quy trình Change Request

```
Khách hàng yêu cầu
        ↓
Ghi vào bảng dưới đây (ngày, nội dung, độ ưu tiên)
        ↓
Tạo GitHub Issue → Tạo branch fix/cr-<số>-<mô-tả>
        ↓
Code → PR → Review → Merge vào main
        ↓
Demo lại cho khách hàng xác nhận
```
