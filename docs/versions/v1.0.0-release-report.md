## 2. Những thay đổi chính so với v0.1.1

### 2.1 Enum Refactoring
- Chuẩn hóa toàn bộ Magic Numbers (0, 1, 2...) sang **C# Enums có type safety**: `Gender`, `WorkPermitType`, `StudentStatus`, `EducationLevel`, `ScholarshipType`, `AccountPermission`, `AttachType`.
- EF Core Fluent API đã sửa `.HasDefaultValue(0)` → `.HasDefaultValue(Enum.Value)` để tương thích SQLite test infrastructure.

### 2.2 Database Seeder Production
- `DatabaseSeeder.SeedCatalogsIfEmptyAsync()` khởi tạo an toàn: Fields, CareerGroups, Careers, Nationality, AdministrativeUnits, tài khoản Admin mặc định.
- Idempotent — chạy nhiều lần không tạo duplicate.

### 2.3 SQL Server Indexes
- Bổ sung 10+ composite & foreign key indexes trên `Employees`, `Students`, `Companies`, `AdministrativeUnits`, `ImportBackups`.
- Tối ưu truy vấn cho dashboard, statistics, search.

### 2.4 Test Suite mở rộng
- Từ 17 tests (v0.1.0) → **83 tests** (v1.0.0)
- Phủ toàn bộ 16 module: Enum roundtrip, RBAC, Auth lockout, Import/Export, Dashboard, Statistics, Search, Family Visitors, Accommodations, Inspections, Legal Documents, Legacy Sync, Database Schema.

### 2.5 Self-Contained Deployment
- Gói triển khai `IRM-production-deploy.zip` chạy trực tiếp trên Windows, không cần cài .NET SDK/Runtime.
- Bao gồm PowerShell auto-installer (`install.ps1`, `quick-install.ps1`).

## 6. Known Limitations

- WPF legacy binary chưa build được (thiếu .NET Framework 4.5.2 Developer Pack)
- Manual browser UAT chưa thực hiện (cần tester nghiệp vụ)
- Customer production database chưa test (cần backup từ khách hàng)
- Windows Defender scan chỉ test trên simulation

---

## 7. Hướng dẫn nâng cấp từ v0.1.x

1. Stop Windows Service IRM hiện tại
2. Backup database hiện tại
3. Giải nén `IRM-production-deploy.zip` mới đè lên thư mục cũ
4. Cập nhật `appsettings.json` với connection string hiện tại
5. Start service
6. App tự áp dụng migration khi khởi động
