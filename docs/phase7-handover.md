# Giai đoạn 7 — Bàn giao & Hướng dẫn

> **Trạng thái:** 📋 Todo

## Checklist Bàn giao

### Tài liệu kỹ thuật

- [ ] Source code commit đầy đủ lên GitHub (nhánh `main`)
- [ ] README.md cập nhật đúng phiên bản cuối
- [ ] deploy-guide.md đã kiểm tra sau lần deploy thật
- [ ] Credentials bàn giao qua kênh bảo mật

### Hướng dẫn Sử dụng (cho người dùng cuối)

- [ ] Đăng nhập và đổi mật khẩu lần đầu
- [ ] Thêm/sửa/xóa hồ sơ lao động
- [ ] Import dữ liệu từ Excel
- [ ] Xuất báo cáo
- [ ] Xem Dashboard và đọc thống kê

### Hướng dẫn Quản trị

- [ ] Cách backup database định kỳ
- [ ] Cách thêm/xóa tài khoản người dùng
- [ ] Cách cập nhật phiên bản mới
- [ ] Cách đọc log lỗi khi hệ thống có sự cố

### Hoàn tất

- [ ] Khách hàng nhận đủ tài liệu và xác nhận
- [ ] Đã training ít nhất 1 buổi cho nhân viên sử dụng
- [ ] Quản trị viên phía khách hàng tự reset mật khẩu và backup DB được
- [ ] Biên bản bàn giao được 2 bên ký
